# Project Documentation Starter

This documentation structure is designed for AI-assisted development and human handoff.

## Files

- `AGENTS.md` — AI development contract and execution workflow.
- `docs/PRD.md` — product requirements and scope.
- `docs/ARCHITECTURE.md` — technical architecture, data flow, folder structure, and dependencies.
- `docs/DESIGN.md` — visual design system and reference-image interpretation.
- `docs/RULES.md` — coding, naming, responsive, SEO, change-management, and documentation rules.
- `docs/TASKS.md` — module-level implementation plan and status.
- `docs/MEMORY.md` — current project state, decisions, completed work, and next continuation point.
- `docs/TECH_STACK.md` — approved technology stack and stack decision history.

## Reference images

Do **not** store client/reference screenshots in this repository's reference folder.

Reference screenshots should be supplied to the AI/developer at the time they are needed. The screenshots are inputs for visual analysis, not project assets.

## Important

These files are living project documentation. The AI/developer must update the relevant files as part of development rather than requiring the owner to manually maintain them.
